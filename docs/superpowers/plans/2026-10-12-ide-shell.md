# YAL IDE 기본 틀 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 프로젝트 목록(추가/삭제/선택)과 프로젝트별 Claude Code 터미널, 프로젝트별 작업 상태(평상시/작업 중/작업 끝/입력 필요) 표시를 가진 Electron 데스크톱 IDE의 1단계를 만든다.

**Architecture:** Electron 메인 프로세스에 순수 로직 모듈(ProjectRegistry, Provisioner, TerminalManager, StatusTracker, claudeSessions, cliCheck)을 두고, 작업 상태는 Claude Code 훅(`--settings`로 주입)이 상태 파일에 기록한 것을 StatusTracker가 읽어 얻는다. 의존성(pty, 파일 시스템, CLI 실행)은 주입해서 단위 테스트한다. Electron/node-pty에 닿는 코드는 얇은 어댑터(`ptyAdapter`, `index.ts`)로 분리한다. 렌더러는 React로 목록과 xterm.js 터미널을 그리고, preload의 `window.yal` API로만 메인과 통신한다.

**Tech Stack:** Electron, electron-vite, React 18, TypeScript, xterm.js(`@xterm/xterm`, `@xterm/addon-fit`), node-pty, vitest

**Spec:** `docs/superpowers/specs/2026-10-12-ide-shell-design.md`

## Global Constraints

- 앱은 Electron 독립 데스크톱 앱이며 UI는 React + TypeScript (스펙 §3)
- 터미널은 xterm.js + node-pty, Claude 연결은 터미널에서 `claude` 실행 (스펙 §3)
- 기존 Claude 세션이 있으면 `claude --continue`, 없으면 `claude` (스펙 §5, §6)
- 프로젝트 목록은 앱 데이터 폴더의 JSON(`projects.json`)에 저장 (스펙 §3)
- 파일 탐색기는 만들지 않는다 (스펙 §4)
- 프로젝트 삭제는 목록과 세션만 제거하고 폴더·파일은 절대 건드리지 않는다 (스펙 §5, §6)
- Provisioner는 이미 있는 파일을 절대 덮어쓰지 않고, 생성한 파일 목록을 사용자에게 보여 준다 (스펙 §5)
- `claude` 또는 `codex` CLI가 없거나 로그인되지 않으면 터미널 대신 원인과 해결 방법을 담은 안내 화면을 보여 준다 (스펙 §7)
- 등록된 폴더가 사라지면 목록에 "경로 없음"으로 표시하고 세션을 시작하지 않는다 (스펙 §7)
- 이미 등록된 경로는 중복으로 거부한다 (스펙 §7)
- `scripts/gpt.sh`는 `--approve-for-me`에 의존하며, 이 옵션의 의미를 프로젝트 등록 시 한 번 안내한다 (스펙 §10)
- 작업 상태는 `idle | working | done | attention` 4가지이며, Claude Code 훅(`--settings`)이 기록한 상태 파일로만 판단한다. 화면 출력 해석이나 타이머 추측을 쓰지 않는다 (스펙 §5)
- 상태 파일이 없거나 깨졌으면 `idle`, 훅 상태 쓰기는 원자적(임시 파일 후 rename)이어야 한다 (스펙 §5)
- `done`은 사용자가 그 프로젝트를 선택하면 `idle`이 된다 (스펙 §5)
- `node`가 없으면 상태 표시만 비활성화하고 터미널은 동작하며 안내를 보여 준다 (스펙 §10)
- GPT 모델은 `gpt-6.1-sol`로 고정한다. `scripts/gpt.sh`와 프로젝트에 생성되는 `gpt.sh` 템플릿 모두 `--model gpt-6.1-sol`을 명시하며, 바꾸려면 `GPT_MODEL` 환경변수를 쓴다 (사용자 요구)
- 구현 담당: 각 Task의 코드는 `scripts/gpt.sh`로 GPT에게 위임하고, Claude는 지시서 작성·테스트 실행·검수·통합을 맡는다 (CLAUDE.md의 역할 분담)
- 커밋 단계(Commit)는 사용자가 커밋을 허락한 경우에만 실행한다. 커밋 메시지 끝에는 `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`를 붙인다.

## Review Focus

스펙이 암시하지만 테스트 항목에 명시되지 않은, 실제로 문제가 되기 쉬운 입력·상황이다. 각 항목은 해당 Task의 테스트로 고정한다.

1. `projects.json`이 깨졌거나 쓰다 만 상태 → 앱이 죽지 않고 빈 목록으로 시작하며 원본을 백업한다 (Task 2)
2. 경로에 공백·한글이 있거나 끝에 구분자가 붙었거나 대소문자만 다른 중복 경로 (Task 2, Task 3)
3. `scripts`가 파일이거나 폴더가 쓰기 불가 → 기존 파일을 건드리지 않고 오류를 결과로 보고하며 앱은 계속 동작 (Task 3)
4. 같은 프로젝트를 연속으로 두 번 시작(더블클릭) → pty가 중복 생성되지 않음. 종료 후 재시작 시 이전 세션의 늦은 종료 이벤트가 새 세션을 죽이지 않음. 출력 버퍼가 무한히 커지지 않음 (Task 5)
5. 실행 중인 프로젝트를 삭제 → 세션만 종료되고 폴더는 그대로. 폴더가 사라진 프로젝트는 pty를 띄우지 않음 (Task 2, Task 5)
6. 상태 파일이 비었거나 깨졌거나 알 수 없는 값이 들어 있음 → `idle`로 취급하고 죽지 않음. 한 프로젝트의 상태가 다른 프로젝트로 새지 않음 (Task 6)
7. 권한 요청 후 승인으로 작업이 재개됨 → `attention`에 머물지 않고 `working`으로 돌아옴. `idle_prompt` 알림이 `done`을 `attention`으로 덮어쓰지 않음 (Task 6)
8. 세션이 종료되거나 프로젝트가 삭제되면 남은 상태 파일 때문에 "작업 중"이 계속 표시되지 않음 (Task 6, Task 7)

`src/shared/types.ts`:
```ts
export interface ProjectRecord {
  id: string
  name: string
  path: string
  addedAt: string
}

export interface ProjectView extends ProjectRecord {
  exists: boolean
}

export interface ProvisionResult {
  created: string[]
  skipped: string[]
  errors: { file: string; message: string }[]
}

export interface CliStatus {
  name: 'claude' | 'codex' | 'node'
  installed: boolean
  loggedIn: boolean | null
  detail: string
}

/** idle=평상시, working=작업 중, done=작업 끝(컨펌 대기), attention=입력 필요 */
export type ProjectStatus = 'idle' | 'working' | 'done' | 'attention'

export type AddProjectResult =
  | { ok: true; project: ProjectView; provision: ProvisionResult }
  | { ok: false; reason: 'cancelled' | 'duplicate' | 'invalid'; message: string }

export type StartTerminalResult = { ok: true; buffer: string } | { ok: false; reason: string }

export const IPC = {
  listProjects: 'projects:list',
  addProject: 'projects:add',
  removeProject: 'projects:remove',
  checkEnv: 'env:check',
  runningTerminals: 'terminal:running',
  projectStatuses: 'status:list',
  acknowledgeProject: 'status:acknowledge',
  startTerminal: 'terminal:start',
  writeTerminal: 'terminal:write',
  resizeTerminal: 'terminal:resize',
  terminalData: 'terminal:data',
  terminalExit: 'terminal:exit'
} as const

export interface YalApi {
  listProjects(): Promise<ProjectView[]>
  addProject(): Promise<AddProjectResult>
  removeProject(id: string): Promise<void>
  checkEnv(): Promise<CliStatus[]>
  runningTerminals(): Promise<string[]>
  projectStatuses(): Promise<Record<string, ProjectStatus>>
  acknowledgeProject(id: string): Promise<void>
  startTerminal(id: string, cols: number, rows: number): Promise<StartTerminalResult>
  writeTerminal(id: string, data: string): void
  resizeTerminal(id: string, cols: number, rows: number): void
  onTerminalData(cb: (id: string, data: string) => void): () => void
  onTerminalExit(cb: (id: string, exitCode: number) => void): () => void
}
```

- [ ] **Step 2: 실패하는 테스트 작성**

`tests/projectRegistry.test.ts`:
```ts
import { existsSync, mkdirSync, mkdtempSync, readdirSync, rmSync, writeFileSync } from 'node:fs'
import { tmpdir } from 'node:os'
import { dirname, join, sep } from 'node:path'
import { afterEach, beforeEach, describe, expect, it } from 'vitest'
import {
  DuplicateProjectError,
  InvalidProjectPathError,
  ProjectNotFoundError,
  ProjectRegistry
} from '../src/main/projectRegistry'

let root: string
let file: string

beforeEach(() => {
  root = mkdtempSync(join(tmpdir(), 'yal-reg-'))
  file = join(root, 'data', 'projects.json')
})
afterEach(() => rmSync(root, { recursive: true, force: true }))

function makeDir(name: string): string {
  const d = join(root, name)
  mkdirSync(d, { recursive: true })
  return d
}

describe('ProjectRegistry', () => {
  it('adds a project and persists it across instances', () => {
    const dir = makeDir('game one')
    const rec = new ProjectRegistry(file).add(dir)
    expect(rec.name).toBe('game one')
    expect(new ProjectRegistry(file).list().map((p) => p.path)).toEqual([dir])
  })

  it('supports Korean and space characters in paths', () => {
    const dir = makeDir('클로드 프로젝트')
    const reg = new ProjectRegistry(file)
    expect(reg.add(dir).name).toBe('클로드 프로젝트')
  })

  it('rejects the same path added twice, even with a trailing separator', () => {
    const dir = makeDir('dup')
    const reg = new ProjectRegistry(file)
    reg.add(dir)
    expect(() => reg.add(dir + sep)).toThrow(DuplicateProjectError)
  })

  it.runIf(process.platform === 'win32')('treats paths differing only by case as duplicates on Windows', () => {
    const dir = makeDir('CaseGame')
    const reg = new ProjectRegistry(file)
    reg.add(dir)
    expect(() => reg.add(dir.toUpperCase())).toThrow(DuplicateProjectError)
  })

  it('rejects a path that does not exist or is a file', () => {
    const reg = new ProjectRegistry(file)
    expect(() => reg.add(join(root, 'nope'))).toThrow(InvalidProjectPathError)
    const f = join(root, 'a.txt')
    writeFileSync(f, 'x')
    expect(() => reg.add(f)).toThrow(InvalidProjectPathError)
  })

  it('remove drops the entry but leaves the folder and its files untouched', () => {
    const dir = makeDir('keep')
    writeFileSync(join(dir, 'asset.txt'), 'important')
    const reg = new ProjectRegistry(file)
    const rec = reg.add(dir)
    reg.remove(rec.id)
    expect(reg.list()).toEqual([])
    expect(existsSync(join(dir, 'asset.txt'))).toBe(true)
  })

  it('remove throws for an unknown id', () => {
    expect(() => new ProjectRegistry(file).remove('missing')).toThrow(ProjectNotFoundError)
  })

  it('reports exists=false when the folder was deleted after registration', () => {
    const dir = makeDir('vanish')
    const reg = new ProjectRegistry(file)
    reg.add(dir)
    rmSync(dir, { recursive: true })
    expect(reg.list()[0].exists).toBe(false)
  })

  it('starts empty and backs up the file when projects.json is corrupt', () => {
    mkdirSync(dirname(file), { recursive: true })
    writeFileSync(file, '{not json')
```

```ts
import { randomUUID } from 'node:crypto'
import { existsSync, mkdirSync, readFileSync, renameSync, statSync, writeFileSync } from 'node:fs'
import { basename, dirname, resolve } from 'node:path'
import type { ProjectRecord, ProjectView } from '../shared/types'

export class DuplicateProjectError extends Error {
  constructor(path: string) {
    super(`이미 등록된 프로젝트입니다: ${path}`)
    this.name = 'DuplicateProjectError'
  }
}

export class InvalidProjectPathError extends Error {
  constructor(path: string) {
    super(`폴더가 아니거나 존재하지 않습니다: ${path}`)
    this.name = 'InvalidProjectPathError'
  }
}

export class ProjectNotFoundError extends Error {
  constructor(id: string) {
    super(`프로젝트를 찾을 수 없습니다: ${id}`)
    this.name = 'ProjectNotFoundError'
  }
}

function normalize(p: string): string {
  const r = resolve(p)
  return process.platform === 'win32' ? r.toLowerCase() : r
}

function isRecord(v: unknown): v is ProjectRecord {
  const r = v as ProjectRecord
  return (
    !!r &&
    typeof r.id === 'string' &&
    typeof r.name === 'string' &&
    typeof r.path === 'string' &&
    typeof r.addedAt === 'string'
  )
}

function isDirectory(p: string): boolean {
  try {
    return statSync(p).isDirectory()
  } catch {
    return false
  }
}

export class ProjectRegistry {
  private projects: ProjectRecord[] = []

  constructor(private readonly file: string) {
    this.load()
  }

  list(): ProjectView[] {
    return this.projects.map((p) => ({ ...p, exists: isDirectory(p.path) }))
  }

  get(id: string): ProjectRecord | undefined {
    return this.projects.find((p) => p.id === id)
  }

  add(path: string): ProjectRecord {
    const abs = resolve(path)
    if (!isDirectory(abs)) throw new InvalidProjectPathError(abs)
    if (this.projects.some((p) => normalize(p.path) === normalize(abs))) {
      throw new DuplicateProjectError(abs)
    }
    const record: ProjectRecord = {
      id: randomUUID(),
      name: basename(abs) || abs,
      path: abs,
      addedAt: new Date().toISOString()
    }
    this.projects.push(record)
    this.save()
    return record
  }

  remove(id: string): ProjectRecord {
    const idx = this.projects.findIndex((p) => p.id === id)
    if (idx < 0) throw new ProjectNotFoundError(id)
    const [removed] = this.projects.splice(idx, 1)
    this.save()
    return removed
  }

  private load(): void {
    if (!existsSync(this.file)) return
    try {
      const data: unknown = JSON.parse(readFileSync(this.file, 'utf8'))
      if (!Array.isArray(data)) throw new Error('projects.json is not an array')
      this.projects = data.filter(isRecord)
    } catch {
      try {
        renameSync(this.file, `${this.file}.corrupt-${Date.now()}`)
      } catch {
        // 백업 실패는 무시하고 빈 목록으로 시작한다.
      }
      this.projects = []
    }
  }

  private save(): void {
    mkdirSync(dirname(this.file), { recursive: true })
    const tmp = `${this.file}.tmp`
    writeFileSync(tmp, JSON.stringify(this.projects, null, 2), 'utf8')
    renameSync(tmp, this.file)
  }
}
```

```ts
import { existsSync, mkdirSync, writeFileSync } from 'node:fs'
import { dirname, join } from 'node:path'
import type { ProvisionResult } from '../shared/types'
import { claudeMd, GPT_SH } from './templates'

interface Target {
  rel: string
  content: string
  mode: number
}

export function provision(projectPath: string, projectName: string): ProvisionResult {
  const result: ProvisionResult = { created: [], skipped: [], errors: [] }
  const targets: Target[] = [
    { rel: 'CLAUDE.md', content: claudeMd(projectName), mode: 0o644 },
    { rel: 'scripts/gpt.sh', content: GPT_SH, mode: 0o755 }
  ]

  for (const t of targets) {
    const abs = join(projectPath, ...t.rel.split('/'))
    try {
      if (existsSync(abs)) {
        result.skipped.push(t.rel)
        continue
      }
      mkdirSync(dirname(abs), { recursive: true })
      // 'wx': 파일이 이미 있으면 쓰지 않고 실패한다 (덮어쓰기 방지).
      writeFileSync(abs, t.content, { encoding: 'utf8', flag: 'wx', mode: t.mode })
      result.created.push(t.rel)
    } catch (e) {
      result.errors.push({ file: t.rel, message: (e as Error).message })
    }
  }
  return result
}
```

```ts
export interface PtyProcess {
  onData(cb: (data: string) => void): void
  onExit(cb: (e: { exitCode: number }) => void): void
  write(data: string): void
  resize(cols: number, rows: number): void
  kill(): void
}

export type PtySpawn = (
  file: string,
  args: string[],
  opts: { cwd: string; cols: number; rows: number; env?: Record<string, string> }
) => PtyProcess

export interface TerminalDeps {
  spawn: PtySpawn
  hasSession(path: string): boolean
  pathExists(path: string): boolean
  platform?: NodeJS.Platform
  maxBuffer?: number
  /** `claude` 인자 맨 앞에 붙는 값 (예: ['--settings', settingsPath]) */
  extraArgs?: string[]
  /** pty 환경변수에 추가할 값 (예: 프로젝트 id, 상태 폴더) */
  envFor?(id: string): Record<string, string>
}

export interface TerminalEvents {
  onData(id: string, data: string): void
  onExit(id: string, exitCode: number): void
}

export class ProjectPathMissingError extends Error {
  constructor(path: string) {
    super(`프로젝트 폴더를 찾을 수 없습니다: ${path}`)
    this.name = 'ProjectPathMissingError'
  }
}

interface Session {
  pty: PtyProcess
  buffer: string
  alive: boolean
}

const DEFAULT_MAX_BUFFER = 200_000

export class TerminalManager {
  private readonly sessions = new Map<string, Session>()

  constructor(
    private readonly deps: TerminalDeps,
    private readonly events: TerminalEvents
  ) {}

  start(id: string, path: string, cols = 120, rows = 30): void {
    if (this.sessions.get(id)?.alive) return
    if (!this.deps.pathExists(path)) throw new ProjectPathMissingError(path)

    const claudeArgs = [
      ...(this.deps.extraArgs ?? []),
      ...(this.deps.hasSession(path) ? ['--continue'] : [])
    ]
    const isWin = (this.deps.platform ?? process.platform) === 'win32'
    const file = isWin ? 'cmd.exe' : 'claude'
    const args = isWin ? ['/c', 'claude', ...claudeArgs] : claudeArgs

    const max = this.deps.maxBuffer ?? DEFAULT_MAX_BUFFER
    const pty = this.deps.spawn(file, args, {
      cwd: path,
      cols,
      rows,
      env: this.deps.envFor?.(id)
    })
    const session: Session = { pty, buffer: '', alive: true }
    this.sessions.set(id, session)

    pty.onData((data) => {
      if (this.sessions.get(id) !== session) return
      session.buffer = (session.buffer + data).slice(-max)
      this.events.onData(id, data)
    })
    pty.onExit(({ exitCode }) => {
      // 교체되거나 kill된 세션의 늦은 종료 이벤트는 무시한다.
      if (this.sessions.get(id) !== session) return
      session.alive = false
      this.events.onExit(id, exitCode)
    })
  }

  isRunning(id: string): boolean {
    return this.sessions.get(id)?.alive === true
  }

  getBuffer(id: string): string {
    return this.sessions.get(id)?.buffer ?? ''
  }

  runningIds(): string[] {
    return [...this.sessions.entries()].filter(([, s]) => s.alive).map(([id]) => id)
  }

  write(id: string, data: string): void {
    const s = this.sessions.get(id)
    if (s?.alive) s.pty.write(data)
  }

  resize(id: string, cols: number, rows: number): void {
    const s = this.sessions.get(id)
    if (s?.alive) s.pty.resize(cols, rows)
  }

  kill(id: string): void {
    const s = this.sessions.get(id)
    if (!s) return
    this.sessions.delete(id)
    try {
      s.pty.kill()
    } catch {
      // 이미 종료된 프로세스는 무시한다.
    }
  }

  killAll(): void {
    for (const id of [...this.sessions.keys()]) this.kill(id)
  }
}
```

```js
'use strict'
// Claude Code 훅이 실행한다: node yal-hook.cjs <Event>
// 환경변수 YAL_STATUS_DIR, YAL_PROJECT_ID 가 있을 때만 상태 파일을 갱신한다.
const fs = require('node:fs')
const path = require('node:path')

const VALID = ['idle', 'working', 'done', 'attention']

function nextStatus(current, event, payload) {
  switch (event) {
    case 'UserPromptSubmit':
      return 'working'
    case 'Stop':
      return 'done'
    case 'SessionEnd':
      return 'idle'
    case 'PostToolUse':
      return current === 'attention' ? 'working' : null
    case 'Notification': {
      const p = payload || {}
      if (p.notification_type === 'idle_prompt') return null
      if (typeof p.message === 'string' && /waiting for your input/i.test(p.message)) return null
      return 'attention'
    }
    default:
      return null
  }
}

function readCurrent(file) {
  try {
    const s = JSON.parse(fs.readFileSync(file, 'utf8')).state
    return VALID.includes(s) ? s : 'idle'
  } catch {
    return 'idle'
  }
}

function writeStatus(file, state) {
  fs.mkdirSync(path.dirname(file), { recursive: true })
  const body = JSON.stringify({ state, ts: Date.now() })
  const tmp = `${file}.${process.pid}.tmp`
  fs.writeFileSync(tmp, body)
  try {
    fs.renameSync(tmp, file)
  } catch {
    fs.writeFileSync(file, body)
    try {
      fs.rmSync(tmp, { force: true })
    } catch {
      // 임시 파일 정리 실패는 무시한다.
    }
  }
}

function main() {
  const event = process.argv[2]
  const dir = process.env.YAL_STATUS_DIR
  const id = process.env.YAL_PROJECT_ID
  if (!event || !dir || !id) return

  const file = path.join(dir, `${id}.json`)
  let raw = ''
  let done = false
  const finish = () => {
    if (done) return
    done = true
    let payload = {}
    try {
      payload = JSON.parse(raw)
    } catch {
      // payload 없이도 이벤트 이름만으로 처리한다.
    }
    const next = nextStatus(readCurrent(file), event, payload)
    if (next) writeStatus(file, next)
    process.exit(0)
  }
  const timer = setTimeout(finish, 2000)
  process.stdin.on('data', (d) => {
    raw += d
  })
  process.stdin.on('end', () => {
    clearTimeout(timer)
    finish()
  })
  process.stdin.on('error', () => {
    clearTimeout(timer)
    finish()
  })
}

module.exports = { nextStatus }

if (require.main === module) main()
```

```ts
import { mkdirSync, readFileSync, rmSync } from 'node:fs'
import { join } from 'node:path'
import type { ProjectStatus } from '../shared/types'

const VALID: ProjectStatus[] = ['idle', 'working', 'done', 'attention']

export class StatusTracker {
  constructor(private readonly dir: string) {
    mkdirSync(dir, { recursive: true })
  }

  get(id: string): ProjectStatus {
    const file = this.file(id)
    if (!file) return 'idle'
    try {
      const state = JSON.parse(readFileSync(file, 'utf8')).state as ProjectStatus
      return VALID.includes(state) ? state : 'idle'
    } catch {
      return 'idle'
    }
  }

  statuses(ids: string[]): Record<string, ProjectStatus> {
    return Object.fromEntries(ids.map((id) => [id, this.get(id)]))
  }

  reset(id: string): void {
    const file = this.file(id)
    if (!file) return
    try {
      rmSync(file, { force: true })
    } catch {
      // 삭제 실패는 다음 훅 갱신이 덮어쓰므로 무시한다.
    }
  }

  acknowledge(id: string): void {
    if (this.get(id) === 'done') this.reset(id)
  }

  private file(id: string): string | null {
    // 프로젝트 id는 UUID다. 경로 구분자가 있으면 상태 폴더 밖을 가리킬 수 있어 거부한다.
    if (!id || /[\\/]|\.\./.test(id)) return null
    return join(this.dir, `${id}.json`)
  }
}
```

```ts
import { join } from 'node:path'
import hookSource from './hook/yal-hook.cjs?raw'

export const HOOK_EVENTS = [
  'UserPromptSubmit',
  'Stop',
  'Notification',
  'PostToolUse',
  'SessionEnd'
] as const

export function buildSettings(
  scriptPath: string,
  nodeCommand = 'node'
): { hooks: Record<string, unknown> } {
  // 훅 명령은 셸이 해석하므로 역슬래시 대신 슬래시 경로를 쓴다.
  const script = scriptPath.replace(/\\/g, '/')
  const hooks: Record<string, unknown> = {}
  for (const ev of HOOK_EVENTS) {
    hooks[ev] = [{ hooks: [{ type: 'command', command: `${nodeCommand} "${script}" ${ev}` }] }]
  }
  return { hooks }
}

export function installHooks(dir: string): {
  scriptPath: string
  settingsPath: string
  statusDir: string
} {
  const scriptPath = join(dir, 'yal-hook.cjs')
  const settingsPath = join(dir, 'claude-settings.json')
  const statusDir = join(dir, 'status')
  mkdirSync(statusDir, { recursive: true })
  writeFileSync(scriptPath, hookSource, 'utf8')
  writeFileSync(settingsPath, JSON.stringify(buildSettings(scriptPath), null, 2), 'utf8')
  return { scriptPath, settingsPath, statusDir }
}
```

```tsx
import { FitAddon } from '@xterm/addon-fit'
import { Terminal } from '@xterm/xterm'
import '@xterm/xterm/css/xterm.css'
import { useEffect, useRef, useState } from 'react'

type State = 'starting' | 'running' | 'exited' | 'error'

export function TerminalView({ projectId }: { projectId: string }) {
  const host = useRef<HTMLDivElement>(null)
  const [state, setState] = useState<State>('starting')
  const [error, setError] = useState('')
  const [restartKey, setRestartKey] = useState(0)

  useEffect(() => {
    const el = host.current
    if (!el) return
    setState('starting')
    setError('')

    const term = new Terminal({ fontSize: 14, cursorBlink: true, theme: { background: '#1e1e1e' } })
    const fit = new FitAddon()
    term.loadAddon(fit)
    term.open(el)
    fit.fit()

    // 시작 응답이 오기 전의 출력 이벤트는 응답의 buffer에 이미 포함되어 있으므로 버린다.
    let attached = false
    let disposed = false

    const offData = window.yal.onTerminalData((id, data) => {
      if (id === projectId && attached) term.write(data)
    })
    const offExit = window.yal.onTerminalExit((id) => {
      if (id === projectId) setState('exited')
    })
    const input = term.onData((d) => window.yal.writeTerminal(projectId, d))

    void window.yal.startTerminal(projectId, term.cols, term.rows).then((res) => {
      if (disposed) return
      if (!res.ok) {
        setError(res.reason)
        setState('error')
        return
      }
      term.write(res.buffer)
      attached = true
      setState('running')
      window.yal.resizeTerminal(projectId, term.cols, term.rows)
    })

    const ro = new ResizeObserver(() => {
      fit.fit()
      window.yal.resizeTerminal(projectId, term.cols, term.rows)
    })
    ro.observe(el)

    return () => {
      disposed = true
      ro.disconnect()
      offData()
      offExit()
      input.dispose()
      term.dispose()
    }
  }, [projectId, restartKey])

  return (
    <div className="terminal-wrap">
      <div className="terminal-host" ref={host} />
      {state === 'exited' && (
        <div className="terminal-overlay">
          <p>Claude 세션이 종료되었습니다.</p>
          <button onClick={() => setRestartKey((k) => k + 1)}>다시 시작</button>
        </div>

      {state === 'error' && (
        <div className="terminal-overlay">
          <p>{error}</p>
          <button onClick={() => setRestartKey((k) => k + 1)}>다시 시도</button>
        </div>
      )}
    </div>
  )
}
```

```tsx
import { useCallback, useEffect, useState, type ReactElement } from 'react'
import type { CliStatus, ProjectStatus, ProjectView, ProvisionResult } from '../../shared/types'
import { EnvBanner, ProvisionBanner, SetupGuide } from './components/Notices'
import { ProjectList } from './components/ProjectList'
import { TerminalView } from './components/TerminalView'

export function App() {
  const [projects, setProjects] = useState<ProjectView[]>([])
  const [selectedId, setSelectedId] = useState<string | null>(null)
  const [runningIds, setRunningIds] = useState<string[]>([])
  const [statuses, setStatuses] = useState<Record<string, ProjectStatus>>({})
  const [env, setEnv] = useState<CliStatus[] | null>(null)
  const [provision, setProvision] = useState<{ name: string; result: ProvisionResult } | null>(null)
  const [message, setMessage] = useState('')

  const refresh = useCallback(async () => setProjects(await window.yal.listProjects()), [])

  useEffect(() => {
    void refresh()
    void window.yal.checkEnv().then(setEnv)
  }, [refresh])

  useEffect(() => {
    const poll = () => {
      void window.yal.runningTerminals().then(setRunningIds)
      void window.yal.projectStatuses().then(setStatuses)
    }
    poll()
    const t = setInterval(poll, 1000)
    return () => clearInterval(t)
  }, [])

  // 사용자가 목록에서 프로젝트를 직접 클릭했을 때만 '작업 끝'을 확인한 것으로 보고 평상시로 돌린다.
  // 지금 보고 있는 프로젝트가 끝난 경우에도 초록 표시를 유지해야 하므로 자동으로 확인 처리하지 않는다.
  function handleSelect(id: string) {
    setSelectedId(id)
    if (statuses[id] === 'done') {
      void window.yal.acknowledgeProject(id)
      setStatuses((s) => ({ ...s, [id]: 'idle' }))
    }
  }

  async function handleAdd() {
    setMessage('')
    const res = await window.yal.addProject()
    if (!res.ok) {
      if (res.reason !== 'cancelled') setMessage(res.message)
      return
    }
    await refresh()
    setSelectedId(res.project.id)
    setProvision({ name: res.project.name, result: res.provision })
  }

  async function handleRemove(p: ProjectView) {
    const ok = window.confirm(
      `"${p.name}"을(를) 목록에서 제거할까요?\n실행 중인 Claude 세션은 종료되며, 폴더와 파일은 삭제되지 않습니다.`
    )
    if (!ok) return
    await window.yal.removeProject(p.id)
    if (selectedId === p.id) setSelectedId(null)
    await refresh()
  }

  const selected = projects.find((p) => p.id === selectedId) ?? null
  const claude = env?.find((s) => s.name === 'claude')
  const claudeBlocked = claude !== undefined && !claude.installed

  let main: ReactElement
  if (claudeBlocked && claude) main = <SetupGuide status={claude} />
  else if (!selected) main = <div className="guide">왼쪽에서 프로젝트를 선택하세요.</div>
  else if (!selected.exists)
    main = (
      <div className="guide">
        <h2>경로 없음</h2>
        <p>{selected.path}</p>
        <p>폴더가 이동되었거나 삭제되었습니다. 목록에서 제거한 뒤 다시 추가하세요.</p>
      </div>
    )
  else main = <TerminalView key={selected.id} projectId={selected.id} />

  return (
    <div className="app">
      <ProjectList
        projects={projects}
        selectedId={selectedId}
        runningIds={runningIds}
        statuses={statuses}
        onSelect={handleSelect}
        onAdd={() => void handleAdd()}
        onRemove={(p) => void handleRemove(p)}
      />
      <main className="main">
        {env && <EnvBanner statuses={env} />}
        {message && <div className="banner warn">{message}</div>}
        {provision && (
          <ProvisionBanner
            projectName={provision.name}
            result={provision.result}
            onClose={() => setProvision(null)}
          />
        )}
        {main}
      </main>
    </div>
  )
}
```
