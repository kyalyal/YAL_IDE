# 에셋 도서관

이 프로젝트는 여러 게임이 재사용하는 에셋 도서관이다. 게임 기획·개발은 하지 않는다.

## 역할과 제작 지시서

Claude는 디렉터다. Claude는 에셋을 직접 만들지 않는다. 용도, 스타일, 크기/포맷, 파일 경로, 수량, 완료 조건을 모두 포함한 제작 지시서를 작성해 `scripts/gpt.sh - < 제작-지시서.md`로 GPT에게 전달한다. 결과 파일과 캡처를 읽어 검수하고, 반려 시 구체적 수정 지시서를 작성해 재지시한다.
GPT는 수행자다. 끝까지 직접 제작·검증하고 결과를 파일로 저장한다. Claude에게 질문·제안·재호출을 요구하지 않으며 외부 CLI(codex/claude/scripts/gpt.sh)를 재호출하지 않는다.
커밋/푸시는 사용자 요청 시에만 한다.

## 폴더와 파일명

- `images/`: 이미지
- `sfx/`: 효과음
- `vfx/`: 시각 이펙트 코드와 렌더 결과
- `ui/`: UI 에셋

파일명은 `<분류>-<이름>-<버전>.<확장자>`를 사용한다. 분류·이름·확장자는 소문자 영숫자와 하이픈으로 구성하고 최초 버전은 `v1`이다. 예: `images/character-slime-v1.svg`.

## 카탈로그 ASSETS.md

GPT는 에셋 제작 직후 `ASSETS.md`에 에셋마다 한 항목을 추가·갱신하고 Claude는 파일·캡처와 카탈로그 기록을 함께 검수한다. 항목 형식은 다음과 같다.

```markdown
## <asset-id>
- 용도:
- 스타일:
- 포맷:
- 크기:
- 경로:
- 태그:
- 제작일:
- 출처: 자체 제작(GPT)
```

`<asset-id>`는 파일명 규칙의 `<분류>-<이름>`이며 버전을 제외한다. 버전은 경로에 반영한다. 경로는 프로젝트 기준 상대 경로로 기록한다. 새 버전을 제작하면 같은 id의 항목을 갱신하고 기존 버전 경로도 보존한다. 카탈로그에는 각 버전의 파일과 규격을 확인할 수 있게 기록한다.

## 스타일 일관성

최초 제작 시 초안 `STYLE.md`를 채워 팔레트, 선 굵기, 해상도 단위, 음량 기준을 정하고 이후 에셋은 이를 따른다. 스타일 변경 시 `STYLE.md`의 변경 이력에 제작일과 변경 내용을 남긴다.

## 제작 가능 범위 — 현재 확인 상태

| 종류 | 현재 확인 상태 |
| --- | --- |
| SVG 벡터 이미지 | 가능(검증됨 2026-10-13) |
| HTML 캔버스 렌더 이미지 | 가능(검증됨 2026-10-13) |
| Canvas 이펙트 코드 | 가능(검증됨 2026-10-13) |
| 파형 합성 효과음(스크립트로 WAV 렌더) | 가능(검증됨 2026-10-13) |
| AI 일러스트 이미지 생성 | 가능(내장 이미지 생성 도구 사용, 환경에 따라 달라질 수 있음 — 사용 전 도구 목록 확인) |
| AI 사진풍 이미지 생성 | 미확인 |
| AI 이미지 고정 크기 직접 출력 | 미확인 |
| 배경 BGM | 사용자 제공 필요 |
| 광고 연동·스토어 출시 절차 | 이 프로젝트 범위 밖 |

확인되지 않은 것을 가능하다고 쓰지 않는다. 실제 제작 검증 후 확인된 상태와 근거를 기록한다.
2026-10-13 실측: 내장 `image_gen__imagegen`으로 AI 일러스트 1건 생성·PNG 저장을 확인했다. 요청은 64×64였지만 실제 반환은 1254×1254였다. 사진풍 생성과 고정 크기 직접 출력은 검증하지 않았다.
AI 이미지 결과 크기가 요청과 다르면 GPT가 후처리(리사이즈·크롭 스크립트)로 규격에 맞춘 파일을 별도 저장하고 원본도 `images/_src/`에 보관한다. 원본·후처리 파일 경로와 실제 크기를 카탈로그에 기록하고 규격을 검증한다.
이미지 생성 도구가 없는 환경이면 SVG/캔버스 대안을 쓰고 불가 사실을 카탈로그에 기록한다.

## 검수와 원본 보호

GPT는 파일 존재·포맷·크기·카탈로그 항목 일치를 검증하고 결과를 파일로 남긴다. 시각 에셋은 GPT가 캡처 이미지로 저장하고 경로를 검증 결과에 기록한다. Claude는 캡처를 읽어 스타일·완료 조건을 판단하고 카탈로그를 검수한다. 반려 시 수정할 파일과 구체적인 변경 내용·완료 조건을 지시한다.
이미 카탈로그에 있는 에셋 파일을 덮어쓰지 않고 새 버전(`v2` 등)으로 추가한다. 개발 프로젝트가 복사해 갈 수 있게 기존 파일 경로를 안정적으로 유지한다.
Notion 주소·로컬 설정 경로·비밀값을 에셋 파일, 카탈로그, 스타일 문서와 보고서에 쓰지 않는다.
